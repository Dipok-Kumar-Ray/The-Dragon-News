## 🎯 পেইজ পরিচিতি

**Donation Details Page** হল একটি প্রাইভেট রুট যা শুধুমাত্র লগইন করা ব্যবহারকারীরা দেখতে পারেন। এই পেইজে একটি নির্দিষ্ট খাদ্য দানের সম্পূর্ণ বিস্তারিত তথ্য প্রদর্শিত হয়।

### 🔐 অ্যাক্সেস নিয়ন্ত্রণ
- **প্রাইভেট রুট**: শুধুমাত্র লগইন করা ব্যবহারকারীরা অ্যাক্সেস করতে পারেন
- **রোল-বেসড ফিচার**: বিভিন্ন ব্যবহারকারীর জন্য বিভিন্ন ফিচার
- **ডাইনামিক কন্টেন্ট**: ব্যবহারকারীর ধরন অনুযায়ী কন্টেন্ট পরিবর্তন

## ✨ প্রধান বৈশিষ্ট্যসমূহ

### 📊 ডোনেশন তথ্য প্রদর্শন
- **শিরোনাম**: ডোনেশনের নাম
- **বিবরণ**: খাবারের ধরন, পরিমাণ, পিকআপ নির্দেশনা
- **রেস্তোরাঁর তথ্য**: নাম ও অবস্থান
- **সময়সূচী**: পিকআপের সময়সীমা
- **স্ট্যাটাস**: বর্তমান অবস্থা (উপলব্ধ, রিকুয়েস্ট করা হয়েছে, ইত্যাদি)

### ❤️ প্রিয় তালিকা ব্যবস্থাপনা
```jsx
// প্রিয় তালিকায় যোগ/সরানো
const handleAddToFavorites = async () => {
  if (isFavorite) {
    await removeFromFavorites(id);
    toast.success('প্রিয় তালিকা থেকে সরানো হয়েছে');
  } else {
    await addToFavorites(id);
    toast.success('প্রিয় তালিকায় যোগ করা হয়েছে');
  }
};
```

### 📝 রিকুয়েস্ট সিস্টেম (দাতব্য সংস্থার জন্য)
- **মোডাল ভিত্তিক রিকুয়েস্ট**: সুন্দর ইন্টারফেস
- **স্বয়ংক্রিয় তথ্য পূরণ**: ডোনেশন ও ব্যবহারকারীর তথ্য
- **সময় যাচাইকরণ**: নির্দিষ্ট সময়সীমার মধ্যে পিকআপ
- **রিয়েল-টাইম আপডেট**: তাৎক্ষণিক স্ট্যাটাস পরিবর্তন

### ✅ পিকআপ নিশ্চিতকরণ
- **অটো-ডিটেকশন**: গৃহীত রিকুয়েস্টের জন্য বাটন দেখানো
- **ওয়ান-ক্লিক কনফার্মেশন**: সহজ পিকআপ নিশ্চিতকরণ

## 🔌 API ইন্টিগ্রেশন

### 📡 Donations API
```javascript
// ডোনেশন ডিটেইলস পাওয়া
const getDonationById = async (id) => {
  const response = await axios.get(`/api/donations/${id}`, {
    headers: { Authorization: `Bearer ${token}` }
  });
  return response.data.donation;
};

// রিকুয়েস্ট পাঠানো
const requestDonation = async (requestData) => {
  const response = await axios.post('/api/donations/request', requestData, {
    headers: { Authorization: `Bearer ${token}` }
  });
  return response.data;
};

// স্ট্যাটাস আপডেট
const updateDonationStatus = async (donationId, status) => {
  const response = await axios.patch(`/api/donations/${donationId}/status`, 
    { status }, 
    { headers: { Authorization: `Bearer ${token}` } }
  );
  return response.data;
};
```

### ❤️ Favorites API
```javascript
// প্রিয় তালিকায় যোগ
const addToFavorites = async (donationId) => {
  await axios.post('/api/favorites', { donationId }, {
    headers: { Authorization: `Bearer ${token}` }
  });
};

// প্রিয় তালিকা থেকে সরানো
const removeFromFavorites = async (donationId) => {
  await axios.delete(`/api/favorites/${donationId}`, {
    headers: { Authorization: `Bearer ${token}` }
  });
};

// প্রিয় স্ট্যাটাস চেক
const checkIfFavorite = async (donationId) => {
  const response = await axios.get(`/api/favorites/check/${donationId}`, {
    headers: { Authorization: `Bearer ${token}` }
  });
  return response.data.isFavorite;
};
```

### ⭐ Reviews API
```javascript
// রিভিউ যোগ করা
const addReview = async (donationId, reviewData) => {
  const response = await axios.post('/api/reviews', {
    donationId,
    ...reviewData
  }, {
    headers: { Authorization: `Bearer ${token}` }
  });
  return response.data.review;
};

// ডোনেশনের রিভিউ পাওয়া
const getReviewsByDonation = async (donationId) => {
  const response = await axios.get(`/api/reviews/donation/${donationId}`, {
    headers: { Authorization: `Bearer ${token}` }
  });
  return response.data.reviews;
};
```

### 🎯 Effect Hooks
```javascript
// ডেটা লোড করা
useEffect(() => {
  loadDonationData();
}, [id]);

// ডেটা লোড ফাংশন
const loadDonationData = async () => {
  try {
    setLoading(true);
    
    // প্যারালাল API কল
    const [donationData, favoriteStatus, reviewsData] = await Promise.all([
      getDonationById(id),
      user ? checkIfFavorite(id) : Promise.resolve(false),
      getReviewsByDonation(id)
    ]);
    
    setDonation(donationData);
    setIsFavorite(favoriteStatus);
    setReviews(reviewsData);
    
    // ব্যবহারকারীর রিকুয়েস্ট চেক
    if (user && user.role === 'charity') {
      const request = donationData.requests?.find(
        req => req.charityId === user._id
      );
      setUserRequest(request);
    }
  } catch (err) {
    setError('ডোনেশনের তথ্য লোড করতে সমস্যা হয়েছে');
  } finally {
    setLoading(false);
  }
};
```

      text: 'রিকুয়েস্ট করা হয়েছে',

      className: 'badge-primary' 
    }
  };
  
  const config = statusConfig[status] || statusConfig.available;
  return (
    <div className={`badge ${config.className} badge-lg`}>
      {config.text}
    </div>
  );
};
