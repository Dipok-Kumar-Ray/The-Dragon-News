## 🎯 প্রজেক্ট পরিচিতি

এই প্রজেক্টটি একটি সম্পূর্ণ **MERN Stack** অ্যাপ্লিকেশন যা **Google Docs API** ব্যবহার করে যেকোনো Google Docs ডকুমেন্ট পড়তে, বিশ্লেষণ করতে এবং ম্যানেজ করতে পারে।

### 🌟 মূল বৈশিষ্ট্য:
- **গুগল ডকস পড়া**: যেকোনো Google Docs URL দিয়ে ডকুমেন্ট কন্টেন্ট পড়া
- **OAuth Authentication**: Google এর মাধ্যমে নিরাপদ লগইন
- **ডাটাবেস স্টোরেজ**: MongoDB তে ডকুমেন্ট তথ্য সংরক্ষণ
- **রেসপন্সিভ UI**: সব ডিভাইসে কাজ করে
- **বাংলা ইন্টারফেস**: সম্পূর্ণ বাংলা ভাষায় ইউজার ইন্টারফেস

## 🔗 Google Docs API Integration

### API Flow:
```
১. User → Google OAuth → Authorization Code
২. Authorization Code → Google → Access Token  
৩. Access Token → Google Docs API → Document Data
৪. Document Data → Our App → MongoDB Storage
```

### প্রয়োজনীয় Google APIs:
- **Google Docs API**: ডকুমেন্ট পড়ার জন্য
- **Google Drive API**: ফাইল metadata এর জন্য
- **Google OAuth 2.0**: User authentication এর জন্য

## 🚀 ধাপে ধাপে সেটআপ

### ধাপ ১: Google Cloud Console সেটআপ

#### ১.১ প্রজেক্ট তৈরি
```bash
1. https://console.cloud.google.com/ এ যান
2. "Select a project" → "New Project" ক্লিক করুন
3. Project name: "Google Docs Reader"
4. Create ক্লিক করুন
```

#### ১.২ APIs Enable করা
```bash
1. Navigation Menu → "APIs & Services" → "Library"
2. "Google Docs API" খুঁজে Enable করুন
3. "Google Drive API" খুঁজে Enable করুন
```

#### ১.৩ OAuth Consent Screen
```bash
1. "APIs & Services" → "OAuth consent screen"
2. User Type: "External" সিলেক্ট করুন
3. App name: "Google Docs Reader"
4. User support email: আপনার email
5. Developer contact: আপনার email
6. Save and Continue
```

#### ১.৪ Credentials তৈরি
```bash
1. "APIs & Services" → "Credentials"
2. "Create Credentials" → "OAuth client ID"
3. Application type: "Web application"
4. Name: "Google Docs Reader Client"
5. Authorized redirect URIs: 
   - http://localhost:5000/api/auth/google/callback
6. Create ক্লিক করুন
7. Client ID ও Client Secret সেভ করুন
```

```javascript
const response = await fetch('/api/google-docs/extract-id', {

    url: 'https://docs.google.com/document/d/1eAKrg7HjZGCvakBylkNu-dbgSX8ykd7F2oQ5PvoM0Hs/edit'

const data = await response.json();
```

## 🛠️ সমস্যা সমাধান

### ১. সাধারণ সমস্যা

#### MongoDB Connection Error
```bash
# সমস্যা: MongoServerError: connect ECONNREFUSED
# সমাধান:
sudo systemctl start mongodb
# অথবা MongoDB Atlas connection string চেক করুন
```

#### Google OAuth Error  
```bash
# সমস্যা: invalid_client বা redirect_uri_mismatch
# সমাধান:
1. Google Cloud Console এ OAuth credentials চেক করুন
2. Redirect URI সঠিক আছে কিনা দেখুন
3. Client ID/Secret সঠিক আছে কিনা দেখুন
```

#### CORS Error
```bash
# সমস্যা: Access-Control-Allow-Origin error  
# সমাধান:
1. Backend এ CORS middleware চেক করুন
2. CLIENT_URL environment variable চেক করুন
```

### ২. Development Issues

#### Port Already in Use
```bash
# সমস্যা: Port 3000/5000 already in use
# সমাধান:
lsof -ti:3000 | xargs kill -9
lsof -ti:5000 | xargs kill -9
```

#### Environment Variables Not Loading
```bash
# সমস্যা: process.env.VARIABLE undefined
# সমাধান:  
1. .env ফাইল backend/ ডিরেক্টরিতে আছে কিনা চেক করুন
2. require('dotenv').config() আছে কিনা দেখুন
3. Variable name সঠিক আছে কিনা দেখুন
```

### ৩. Google API Issues

#### Document Not Found (404)
```bash
# সমস্যা: Document ID invalid বা access নেই
# সমাধান:
1. Document ID সঠিক আছে কিনা চেক করুন
2. Document public বা shared কিনা দেখুন
3. Google account এ document access আছে কিনা দেখুন
```

#### Permission Denied (403)
```bash
# সমস্যা: OAuth scope বা permission issue
# সমাধান:
1. OAuth consent screen এ scopes চেক করুন
2. User কে re-authorize করান
3. API quotas চেক করুন
```

### ৪. Frontend Issues

#### Build Errors
```bash
# সমস্যা: Module not found বা dependency issues
# সমাধান:
cd frontend
rm -rf node_modules package-lock.json
npm install
npm start
```

#### State Management Issues
```bash
# সমস্যা: Zustand store state update হচ্ছে না
# সমাধান:
1. Store actions সঠিকভাবে call হচ্ছে কিনা দেখুন
2. React DevTools দিয়ে state inspect করুন
```

## 📈 Performance Optimization

### ১. Backend Optimization
```javascript
// MongoDB indexing
DocumentSchema.index({ userId: 1, accessedAt: -1 });
DocumentSchema.index({ title: 'text', content: 'text' });

// API Response caching
app.use('/api', rateLimit({ windowMs: 15 * 60 * 1000, max: 100 }));

// Pagination for large datasets
const documents = await Document.find()
  .skip((page - 1) * limit)
  .limit(limit)
  .select('-content'); // Exclude large content field
```

### ২. Frontend Optimization
```javascript
// React Query for API caching
const { data, isLoading } = useQuery(
  ['documents', page], 
  () => fetchDocuments(page),
  { staleTime: 5 * 60 * 1000 } // 5 minutes cache
);

// Lazy loading components
const DocumentReader = React.lazy(() => import('./DocumentReader'));

const MemoizedDocumentCard = React.memo(DocumentCard);
```
